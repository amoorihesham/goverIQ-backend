# Data Model: Project Bootstrap (Phase 0)

**Feature**: 001-project-bootstrap
**Date**: 2026-05-01
**Source**: `docs/IMPLEMENTATION-PLAN.md` Phase 0 Data Schema + clarifications from `spec.md`

All 17 tables are created in a single advisory-locked migration (FR-001). Schema is
defined in TypeScript via Drizzle in `src/db/schema/<domain>.ts` and migrations are
generated by `drizzle-kit generate`.

**Conventions**:

- All primary keys are UUIDs generated by `gen_random_uuid()` (`pgcrypto` extension
  enabled in the first migration step).
- All timestamps are `timestamptz` and default to `now()` for `created_at` columns.
- Soft-delete columns use `archived_at timestamptz` (No Hard Deletes principle).
- Email columns are stored lowercased; uniqueness checks are case-insensitive.

## Org / Role / Member Domain

### `organizations`

| Column             | Type         | Constraints                                                                                  |
| ------------------ | ------------ | -------------------------------------------------------------------------------------------- |
| `id`               | uuid         | PK                                                                                           |
| `name`             | text         | NOT NULL                                                                                     |
| `name_lower`       | text         | NOT NULL, UNIQUE (generated lowercase of `name`)                                             |
| `slug`             | text         | NOT NULL, UNIQUE                                                                             |
| `description`      | text         | NULL                                                                                         |
| `logo_url`         | text         | NULL                                                                                         |
| `quorum_threshold` | numeric(3,2) | NOT NULL, default `0.50` (0.0–1.0)                                                           |
| `onboarding_step`  | enum         | NOT NULL, default `'PENDING_ROLES'` (values: `PENDING_ROLES`, `PENDING_INVITES`, `COMPLETE`) |
| `archived_at`      | timestamptz  | NULL                                                                                         |
| `created_at`       | timestamptz  | NOT NULL, default `now()`                                                                    |
| `updated_at`       | timestamptz  | NOT NULL, default `now()`                                                                    |

Indexes: `organizations_name_lower_idx` (UNIQUE); `organizations_slug_idx` (UNIQUE).

### `roles`

| Column        | Type        | Constraints                                                            |
| ------------- | ----------- | ---------------------------------------------------------------------- |
| `id`          | uuid        | PK                                                                     |
| `org_id`      | uuid        | NOT NULL, FK → `organizations.id` ON DELETE CASCADE                    |
| `name`        | text        | NOT NULL                                                               |
| `is_owner`    | boolean     | NOT NULL, default `false`                                              |
| `permissions` | text[]      | NOT NULL, default `'{}'` (each entry is one of the 22 permission keys) |
| `created_at`  | timestamptz | NOT NULL, default `now()`                                              |
| `updated_at`  | timestamptz | NOT NULL, default `now()`                                              |

Indexes: `roles_org_idx` on `org_id`; UNIQUE `(org_id, lower(name))` —
case-insensitive name uniqueness within an org. Partial unique index on `(org_id)`
where `is_owner = true` to enforce one Owner role per org.

### `memberships`

| Column      | Type        | Constraints                                         |
| ----------- | ----------- | --------------------------------------------------- |
| `id`        | uuid        | PK                                                  |

| `role_id`   | uuid        | NULL, FK → `roles.id` ON DELETE SET NULL            |
| `joined_at` | timestamptz | NOT NULL, default `now()`                           |

Indexes: UNIQUE `(user_id, org_id)`; `memberships_org_idx` on `org_id`;
`memberships_role_idx` on `role_id`.

### `invitations`

| Column       | Type        | Constraints                                                                          |

| `org_id`     | uuid        | NOT NULL, FK → `organizations.id` ON DELETE CASCADE                                  |

## Vote Domain

### `votes`

| Column           | Type        | Constraints                                                 |
| ---------------- | ----------- | ----------------------------------------------------------- |
| `id`             | uuid        | PK                                                          |
| `meeting_id`     | uuid        | NOT NULL, FK → `meetings.id` ON DELETE CASCADE              |
| `question`       | text        | NOT NULL                                                    |
| `options`        | text[]      | NOT NULL (≥ 2 elements)                                     |
| `status`         | enum        | NOT NULL, default `'OPEN'` (values: `OPEN`, `CLOSED`)       |
| `outcome`        | enum        | NULL (values: `PASSED`, `FAILED`, `TIED`, `QUORUM_NOT_MET`) |
| `result_summary` | jsonb       | NULL (aggregate counts per choice)                          |
| `deadline`       | timestamptz | NOT NULL                                                    |
| `closed_at`      | timestamptz | NULL                                                        |
| `created_at`     | timestamptz | NOT NULL, default `now()`                                   |

Indexes: `votes_meeting_idx` on `meeting_id`; `votes_meeting_status_idx` on
`(meeting_id, status)` — supports the `MEETING_HAS_OPEN_VOTES` guard query.

### `vote_eligibility`

| Column       | Type        | Constraints                             |
| ------------ | ----------- | --------------------------------------- |
| `vote_id`    | uuid        | FK → `votes.id` ON DELETE CASCADE       |
| `member_id`  | uuid        | FK → `memberships.id` ON DELETE CASCADE |
| `created_at` | timestamptz | NOT NULL, default `now()`               |

PK: composite `(vote_id, member_id)`. **Insert-only** at the application layer (snapshot
is immutable after vote creation).

### `ballots`

| Column       | Type        | Constraints                                       |
| ------------ | ----------- | ------------------------------------------------- |
| `id`         | uuid        | PK                                                |
| `vote_id`    | uuid        | NOT NULL, FK → `votes.id` ON DELETE CASCADE       |
| `member_id`  | uuid        | NOT NULL, FK → `memberships.id` ON DELETE CASCADE |
| `choice`     | text        | NOT NULL (must equal one of `votes.options`)      |
| `created_at` | timestamptz | NOT NULL, default `now()`                         |

Indexes: UNIQUE `(vote_id, member_id)` — enforces the one-ballot rule
(`DUPLICATE_BALLOT`).

## Audit Domain

### `audit_logs`

| Column        | Type        | Constraints                                                              |
| ------------- | ----------- | ------------------------------------------------------------------------ |
| `id`          | uuid        | PK                                                                       |
| `org_id`      | uuid        | **NULL allowed** (per spec clarification Q1 — pre-org events)            |
| `actor_id`    | uuid        | NULL allowed (system events have no actor)                               |
| `event`       | text        | NOT NULL (e.g. `user.registered`, `org.created`)                         |
| `entity_type` | text        | NOT NULL                                                                 |
| `entity_id`   | uuid        | NULL allowed                                                             |
| `payload`     | jsonb       | NOT NULL (`{ before, after }` for mutations or `{ data }` for creations) |
| `created_at`  | timestamptz | NOT NULL, default `now()`                                                |

Indexes (per implementation plan):

- `audit_logs_org_created_idx` on `(org_id, created_at DESC)`
- `audit_logs_org_actor_idx` on `(org_id, actor_id)`
- `audit_logs_org_event_idx` on `(org_id, event)`
- `audit_logs_org_entity_idx` on `(org_id, entity_type, entity_id)`

**INSERT-only at the database level**: the application's DB role will be granted only
`INSERT` on this table (UPDATE / DELETE revoked). This grant adjustment lands in
**Phase 5** per the implementation plan; in Phase 0 the table exists with full app-role
permissions.

## State Transitions Summary (for reference)

| Entity                          | States                                                                                    | Transition guards |
| ------------------------------- | ----------------------------------------------------------------------------------------- | ----------------- |
| `organizations.onboarding_step` | `PENDING_ROLES → PENDING_INVITES → COMPLETE`                                              | Phase 2           |
| `meetings.status`               | `DRAFT → SCHEDULED → IN_PROGRESS → COMPLETED`; `SCHEDULED` or `IN_PROGRESS` → `CANCELLED` | Phase 3/4         |
| `votes.status`                  | `OPEN → CLOSED`                                                                           | Phase 4           |
| `minutes.status`                | `DRAFT → FINALIZED` (immutable after); corrections append-only                            | Phase 4           |
| `invitations.status`            | `PENDING → ACCEPTED` / `DECLINED` / `EXPIRED`                                             | Phase 2           |

These transitions are enforced by domain modules in their respective phases. Phase 0
only creates the schema and the columns that hold state; no transition logic ships here.
